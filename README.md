# XDi - Customer Centric Solutions

A modern, responsive website for XDi showcasing customer-centric solutions and services.

## 🚀 Features

- **Single-Page Experience**: Hero, services, case studies, and contact in one scroll
- **Service Showcase**: Detailed offering cards with highlights and capabilities
- **Case Studies Grid**: Metrics-driven stories that prove results
- **Inline Contact Form**: Project inquiry form with real-time validation

## 📁 Project Structure

```
/
├── index.html          # Main landing page
├── css/                # Stylesheets
│   └── styles.css
├── js/                 # JavaScript files
│   └── script.js
└── assets/             # Images and resources
    └── Resources/
```

## 🛠️ Technologies

- HTML5
- CSS3 (with modern features like backdrop-filter, gradients)
- Vanilla JavaScript
- Responsive Design

## 📝 Setup

1. Clone the repository
2. Open `index.html` in a web browser
3. Or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (http-server)
   npx http-server
   ```
